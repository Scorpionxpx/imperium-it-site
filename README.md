# Imperium IT — Site vitrine

Site statique responsive réalisé à partir du support de présentation Imperium IT.

## Activer GitHub Pages

1. Ouvrir **Settings** dans le dépôt.
2. Ouvrir **Pages**.
3. Sélectionner **Deploy from a branch**.
4. Choisir `main` et le dossier `/(root)`.
5. Enregistrer.

Le site sera accessible sur : `https://scorpionxpx.github.io/imperium-it-site/`

Le formulaire est une démonstration front-end : raccordez-le à un service de traitement de formulaires pour recevoir les demandes.
